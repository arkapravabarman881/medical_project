# Smart Hospital Patient Waiting-Time Prediction

## Project Overview
This project aims to predict hospital patient waiting times using Machine Learning techniques.

The goal is to analyze hospital emergency department data and develop predictive models that can help understand patient waiting-time patterns.

## Dataset
The project uses the CDC National Hospital Ambulatory Medical Care Survey (NHAMCS) 2022 dataset.

## Machine Learning Models
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Streamlit (planned)
